# Рубежный контроль №1 по курсу «ПиК ЯП»

Репозиторий содержит решение рубежного контроля №1 по курсу **«Программирование и конструирование языков программирования»** (МГТУ им. Н.Э. Баумана).

## Вариант задания

* **Вариант предметной области:** № 9 — **«Операционная система»** (Класс 1) и **«Компьютер»** (Класс 2).
* **Вариант запросов:** **Б**

### Сущности и связи
1. **Класс `OS` («Операционная система»):**
   * `id`: int — идентификатор ОС;
   * `name`: str — наименование операционной системы;
   * `price`: int/float — количественный признак (стоимость лицензии);
   * `comp_id`: int — внешний ключ для связи один-ко-многим с компьютером.
2. **Класс `Comp` («Компьютер»):**
   * `id`: int — идентификатор компьютера;
   * `name`: str — наименование / назначение компьютера.
3. **Класс `OSComp` («Операционные системы на компьютере»):**
   * `comp_id`: int — идентификатор компьютера;
   * `os_id`: int — идентификатор операционной системы (связь многие-ко-многим).

### Запросы (Вариант Б)
1. **Запрос Б1 (один-ко-многим):** Вывести список всех связанных операционных систем и компьютеров, отсортированный по операционным системам (по названию ОС), сортировка по компьютерам произвольная.
2. **Запрос Б2 (один-ко-многим):** Вывести список компьютеров с количеством операционных систем на каждом компьютере, отсортированный по количеству операционных систем (по убыванию).
3. **Запрос Б3 (многие-ко-многим):** Вывести список всех операционных систем, у которых название заканчивается на «Linux» (адаптация условия «фамилия заканчивается на «ов»» для предметной области с использованием `str.endswith`), и названия их компьютеров.
